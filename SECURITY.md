# LocalPilot Security Policy

LocalPilot is an experimental offline-first macOS assistant.

## Reporting Security Vulnerabilities

Please report suspected vulnerabilities privately to:

**jahvascripts@gmail.com**

Do not publish passwords, API keys, personal information,
private recordings, or exploit details in public issues.

Include reproduction steps and affected components when
possible. Reports will be reviewed by the maintainer.

## Security Considerations

LocalPilot may interact with macOS accessibility,
speech input, and local applications.

Users should review permissions and understand the
assistant's capabilities before granting access.

The software is a development prototype. It has not
undergone an independent security audit.
